# MediMind API Contract

Base URL: `https://<your-backend-url>/api`
Auth: after login, send header `Authorization: Bearer <token>` on every 🔒 endpoint.

## Envelope (all endpoints, no exceptions)

- Success: `{ "data": ... }`
- Failure: `{ "error": { "code": "snake_case_code", "message": "Human readable" } }`
- All field names snake_case. All timestamps UTC ISO-8601. `time_of_day` as `"HH:MM"`.

## Shared object shapes

```jsonc
// user
{ "id": "uuid", "full_name": "...", "email": "...", "phone": null,
  "date_of_birth": null, "profile_picture_url": null, "created_at": "..." }

// medicine (includes its reminders)
{ "id": "uuid", "name": "Metformin", "dosage": "500 mg", "form": "tablet",
  "frequency_per_day": 2, "start_date": "2026-09-01", "end_date": null,
  "instructions": "after food", "is_active": true,
  "reminders": [ { "id": "uuid", "time_of_day": "08:00",
                   "days_of_week": [1,2,3,4,5,6,7], "is_enabled": true } ] }

// today_item — powers the Home Dashboard
{ "reminder_id": "uuid", "medicine_id": "uuid", "medicine_name": "Metformin",
  "dosage": "500 mg", "time_of_day": "08:00",
  "status": "pending|taken|missed|skipped", "log_id": null }
```

## Auth

### `POST /api/auth/register` (P0)
- Request: `{ "full_name": "...", "email": "...", "password": "min 8 chars" }`
- Response 201: `{ "data": { "user": <user>, "token": "<jwt>" } }`
- Errors: `400 validation_error`, `409 email_taken`

### `POST /api/auth/login` (P0)
- Request: `{ "email": "...", "password": "..." }`
- Response 200: `{ "data": { "user": <user>, "token": "<jwt>" } }`
- Errors: `401 wrong_credentials`

### `GET /api/auth/me` 🔒 (P0)
- Response: `{ "data": { "user": <user> } }`
- Used by the Splash screen to auto-login with a stored token.

## Profile

### `GET /api/profile` 🔒 (P1)
### `PUT /api/profile` 🔒 (P1)
- Request: any of `{ "full_name", "phone", "date_of_birth" }`
- Response: `{ "data": { "user": <user> } }`

## Medicines

### `GET /api/medicines` 🔒 (P0) — supports `?search=para&active=true`
- Response: `{ "data": [ <medicine> ] }` (newest first)

### `POST /api/medicines` 🔒 (P0)
- Request:
  ```json
  { "name": "Metformin", "dosage": "500 mg", "form": "tablet",
    "frequency_per_day": 2, "start_date": "2026-09-01", "instructions": "after food",
    "reminder_times": ["08:00", "20:00"], "days_of_week": [1,2,3,4,5,6,7] }
  ```
- Server creates medicine + one reminder per time, in ONE transaction.
- Response 201: `{ "data": <medicine incl. reminders> }`
- Errors: `400 validation_error` (name/dosage required; times must be `HH:MM`)

### `GET /api/medicines/:id` 🔒 (P1)
### `PUT /api/medicines/:id` 🔒 (P1) — same body as POST; replaces its reminders
### `DELETE /api/medicines/:id` 🔒 (P1) — soft delete (`is_active=false`)
- Response: `{ "data": { "id": "uuid" } }`

## Reminders & Today

### `GET /api/reminders/today` 🔒 (P0) — **the Home Dashboard endpoint**
- Response: `{ "data": [ <today_item> ] }` sorted by `time_of_day`
- Status logic: `taken`/`skipped` if today's log exists, else `missed` if the time
  has passed, else `pending`.

### `GET /api/reminders` 🔒 (P1) — user's reminders incl. medicine name
### `POST /api/reminders` 🔒 (P1) — `{ "medicine_id", "time_of_day", "days_of_week" }`
### `PUT /api/reminders/:id` 🔒 (P1) — change time / `is_enabled`
### `DELETE /api/reminders/:id` 🔒 (P1)

## Adherence

### `POST /api/adherence/:reminder_id/mark` 🔒 (P0) — applies to TODAY's dose
- Request: `{ "status": "taken" | "skipped", "note": "optional" }`
- Response: `{ "data": { "log_id": "uuid", "status": "taken", "taken_at": "..." } }`

### `GET /api/adherence/history` 🔒 (P1) — `?from=&to=`, returns logs
### `GET /api/adherence/stats` 🔒 (P1)
- Response: `{ "data": { "taken": 12, "missed": 2, "skipped": 1,
  "rate_percent": 80, "streak_days": 4 } }`

## Error codes (fixed list)

| code | http | meaning |
|---|---|---|
| validation_error | 400 | input failed validation |
| wrong_credentials | 401 | bad email/password |
| unauthorized | 401 | missing/invalid/expired token |
| not_found | 404 | wrong id or belongs to someone else |
| email_taken | 409 | register with existing email |
| internal | 500 | anything else |
